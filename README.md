# 📚 Sistema de Gerenciamento de Livros

Este projeto consiste em um sistema simples de gerenciamento de livros, desenvolvido em Python, com interface de linha de comando (CLI). Ele permite realizar o cadastro, a consulta e a remoção de livros com identificação única.

> Projeto desenvolvido por **Iara Fernandes** como parte da prática de lógica de programação e estruturas de dados em Python.

---

## ✅ Funcionalidades

- Cadastro de livros com ID automático
- Consulta de livros:
  - Todos os livros
  - Por ID
  - Por autor
- Remoção de livros por ID
- Menu interativo com navegação simples
- Feedbacks e mensagens para o usuário em todas as operações

---

## 🛠 Tecnologias Utilizadas

- **Linguagem:** Python 3.x  
- **Paradigma:** Programação estruturada  
- **Armazenamento:** Lista em memória (sem persistência)

---

## 🚀 Como Executar o Projeto

1. Certifique-se de que o Python 3 está instalado em seu sistema.
2. Clone este repositório ou baixe o arquivo `.py` para seu computador.
3. No terminal, navegue até a pasta do projeto e execute o seguinte comando:

```bash
python gerenciador_livros.py
Siga as instruções exibidas no terminal para utilizar o sistema.

🔒 Observações Importantes
Os dados cadastrados não são salvos permanentemente. Ao encerrar o programa, todos os registros são perdidos.

Este projeto tem fins didáticos e pode ser expandido para incluir funcionalidades como persistência em arquivos, interface gráfica ou banco de dados.
